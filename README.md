# ERP Roles — Multi-Platform Taxonomy

[![build](https://github.com/vijayndran/erp-roles/actions/workflows/build.yml/badge.svg)](https://github.com/vijayndran/erp-roles/actions/workflows/build.yml)

A platform-aware taxonomy of ERP job roles. Normalises the messy, platform-ambiguous world of ERP titles into 40 canonical roles across functional / technical / Basis-admin / data / leadership streams, each tagged with the platforms it applies to, plus skills, a one-line JD skeleton, an indicative comp band and the raw aliases that map to it.

> Platform-aware taxonomy of ERP roles across **8 platforms** (SAP S/4HANA & ECC, SAP Business One, Oracle (Fusion / EBS), Microsoft Dynamics 365, Workday, Infor M3, NetSuite, Sage). De-duplicates messy ERP job titles into **40 canonical roles** across functional / technical / Basis-admin / data / leadership streams, each with a one-line JD skeleton, required/preferred skills, an indicative comp band and the raw aliases that map to it — shipped as machine-readable `roles.json` plus a searchable [web page](https://vijayndran.github.io/erp-roles/).

## Career ladders

- **Functional consulting:** ERP Associate Consultant → ERP Functional Consultant → Senior ERP Functional Consultant → ERP Solution Architect → ERP Practice Lead / Head
- **Technical / development:** ERP Technical Consultant → Senior ERP Developer → ERP Technical Architect
- **Basis / admin:** ERP Administrator → ERP Basis / Infrastructure Consultant → Senior ERP Basis Consultant
- **SAP cloud development:** SAP ABAP / RAP Developer → SAP Fiori / UI5 Developer → SAP BTP Developer → ERP Technical Architect
- **Delivery / leadership:** ERP Project Manager → ERP Programme Manager → ERP Practice Lead / Head
